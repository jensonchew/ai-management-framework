# Decision Log

## 2026-10-06 - Project framing
Decision: Frame the effort as an AI-assisted developer productivity initiative for Corporate IT.
Reason: Aligns with current tool adoption and avoids positioning the work as a replacement for existing IDEs or copilots.

## 2026-10-06 - Human-in-the-loop model
Decision: Keep humans responsible for review and final delivery decisions.
Reason: Reduces risk from incorrect AI output and keeps the approach compatible with governance expectations.

## 2026-10-06 - Tooling approach
Decision: Support Visual Studio Pro, GitHub Copilot, and OpenCode as complementary tools.
Reason: Matches the current working environment and avoids unnecessary tool lock-in.

## 2026-10-06 - Pilot-first rollout
Decision: Begin with a controlled pilot before broader expansion.
Reason: Allows the team to validate value, adoption, and control effectiveness before scaling.

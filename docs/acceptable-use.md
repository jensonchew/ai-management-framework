# Acceptable Use

## Allowed
- Drafting code and documentation
- Summarizing incidents or technical notes
- Generating test ideas
- Analyzing non-sensitive examples
- Supporting troubleshooting with reviewed outputs

## Allowed with Review
- AI-generated code suggestions
- AI-assisted debugging steps
- SQL drafts
- Documentation intended for internal use

## Not Allowed
- Unreviewed production changes
- Sharing secrets, passwords, or restricted data
- Treating AI output as authoritative without validation
- Using AI to bypass approval or security processes

## User Expectations
- Review all outputs before use
- Sanitize inputs when needed
- Follow corporate security and compliance rules
- Escalate uncertainties to a reviewer or sponsor

## Examples of Good Practice
- Use sanitized samples instead of live sensitive data
- Ask AI for structure or approach, then validate the result
- Keep a human accountable for final decisions

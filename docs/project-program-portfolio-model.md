# Project, Program, and Portfolio Model

## Project Level
A project is a temporary effort with a defined scope, timeline, and outcome.

## Program Level
A program coordinates multiple related projects to realize broader benefits.

## Portfolio Level
A portfolio groups initiatives so leaders can prioritize, balance risk, allocate capacity, and maximize value.

## How This Scaffold Supports All Three
- Project: charter, requirements, pilot, roadmap, risks, and execution
- Program: coordination across related projects, dependencies, and benefits realization
- Portfolio: prioritization, governance, capacity, and reporting across multiple initiatives

## Common Building Blocks
- Charter or intake
- Requirements or goals
- Roadmap or plan
- Governance and approvals
- Risk and issue tracking
- Metrics and benefits realization
- Communication and decision logs

## Scaling Rule
Use the same structure, but adjust the level of detail to match the management tier.

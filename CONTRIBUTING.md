# Contributing

## Purpose
This repository is intended to remain a clean, reusable framework for project, program, and portfolio management in the AI era.

## What to Contribute
- Improvements to the framework structure
- Clarifications to governance or planning guidance
- Better adaptation guidance
- Corrections to wording, consistency, or layout

## What to Avoid
- Confidential examples
- Organization-specific details that reduce reusability
- Content that turns the repo into a one-off internal artifact

## Contribution Guidelines
- Keep changes consistent with the framework purpose
- Prefer simple, reusable patterns
- Update cross-references if you rename or move documents
- Keep language organization-agnostic unless the change is clearly intentional

## Pull Requests
- Explain what changed and why
- Note any docs that were added, removed, or updated
- Include follow-up items if the change affects related files

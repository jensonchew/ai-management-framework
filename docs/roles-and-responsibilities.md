# Roles and Responsibilities

## Sponsor
- Approves direction and scope
- Supports governance decisions
- Reviews pilot outcomes

## Initiative Owner
- Coordinates the initiative
- Maintains scope and deliverables
- Tracks decisions and risks

## Technical Lead
- Advises on use cases and implementation patterns
- Reviews technical outputs and quality concerns
- Supports pilot evaluation

## Pilot User
- Uses AI within approved bounds
- Provides feedback on value and usability
- Escalates risks or issues

## Reviewer
- Validates outputs before use or release
- Confirms quality, accuracy, and safety

## Stakeholders
- Receive updates
- Provide feedback where relevant
- Support rollout decisions as needed

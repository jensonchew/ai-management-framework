# Data Classification

## Purpose
Define how data should be handled when using AI in Corporate IT workflows.

## Classification Levels
- Public: Safe to share broadly
- Internal: Non-public business information intended for internal use
- Confidential: Sensitive business information requiring tighter control
- Restricted: Highly sensitive information subject to strict access limitations

## Usage Guidance
- Public data may be used with normal caution
- Internal data may be used only if policy and tool approvals allow it
- Confidential data should not be entered into AI tools unless explicitly approved
- Restricted data should not be used unless there is a formal approved process

## Practical Rule
If in doubt, do not paste the data into an AI tool. Use sanitized examples instead.

## Examples of Sensitive Content
- Passwords or secrets
- Internal incident logs containing sensitive identifiers
- Customer or employee information
- Application details tied to restricted systems
- Security findings or vulnerabilities not ready for disclosure

# FAQ

## What is this project?
It is a reusable initiative framework to use AI safely and productively for management, delivery, and support work.

## Is AI replacing developers?
No. The model is human-in-the-loop. AI assists with drafting, analysis, and repetitive work, but humans remain accountable.

## What tools are included?
Visual Studio Pro, GitHub Copilot, and OpenCode are the current tools in scope.

## What tasks are included?
Code drafting, debugging, test generation, documentation, SQL assistance, and incident analysis.

## What data can be used?
Only data allowed by corporate policy and the project’s data-handling rules.

## Who approves expansion?
The sponsor and project stakeholders after pilot review and governance checks.

## Why start with a pilot?
To validate value, safety, and adoption before scaling.

# Use Cases

## 1. Code Drafting
Use AI to draft code snippets, helper methods, or small feature implementations that a developer reviews and integrates.

## 2. Code Explanation
Use AI to explain legacy code, unfamiliar modules, or complex logic so staff can understand the implementation faster.

## 3. Debugging Support
Use AI to suggest likely causes, inspection steps, and candidate fixes for defects or unexpected behavior.

## 4. Test Generation
Use AI to propose unit tests, test cases, and edge-case coverage for existing code.

## 5. Documentation Drafting
Use AI to draft technical notes, implementation summaries, and knowledge-transfer content.

## 6. SQL and Query Assistance
Use AI to help draft or review SQL statements, identify query logic issues, and suggest safer alternatives.

## 7. Incident Analysis
Use AI to summarize incidents, highlight patterns from logs or notes, and propose next troubleshooting steps.

## 8. Knowledge Transfer
Use AI to convert tribal knowledge into written guidance for onboarding, handover, and support continuity.

## Pilot Selection Guidance
Start with low-risk, high-repeatability tasks where human review is easy and the expected productivity gain is visible.

# Presentation Outline

## Slide 1: Title
AI Management Framework

## Slide 2: Problem
- Repetitive development and support work slows delivery
- Staff spend time on drafting, debugging, testing, and documentation
- Knowledge transfer and issue resolution can be slow

## Slide 3: Proposed Approach
- Use AI in a human-in-the-loop model
- Support drafting, analysis, and workflow acceleration
- Leverage existing approved tools

## Slide 4: Tools
- Visual Studio Pro
- GitHub Copilot
- OpenCode

## Slide 5: Use Cases
- Code drafting and explanation
- Debugging assistance
- Test generation
- Documentation drafting
- SQL/query support
- Incident analysis

## Slide 6: Benefits
- Faster delivery
- Reduced manual effort
- Improved consistency and quality
- Better onboarding and knowledge transfer

## Slide 7: Risks and Controls
- Human review required
- Approved tools only
- Sensitive data handling restrictions
- Pilot-first rollout

## Slide 8: Roadmap
- Define pilot
- Run pilot
- Review outcomes
- Expand if successful

## Slide 9: Decision
- Approve pilot
- Confirm participants
- Confirm governance

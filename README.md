# ai-management-framework
A reusable framework for AI-era project, program, and portfolio management, with governance, planning, execution, and public adaptation guidance.

## What This Repo Is For
- A reusable methodology for project, program, and portfolio work
- A structured approach to AI-supported management
- A governance-aware planning and delivery scaffold
- A public framework that others can adapt

## What This Repo Includes
- `docs/index.md` - master documentation index
- `docs/project-charter.md` - project purpose, scope, risks, and success criteria
- `docs/security-and-governance-overview.md` - security and governance baseline
- `docs/data-classification.md` - how to handle internal and sensitive data
- `docs/acceptable-use.md` - allowed and disallowed usage
- `docs/approval-process.md` - approval stages and exception handling
- `docs/roadmap.md` - phased delivery roadmap
- `docs/implementation-plan.md` - pilot and rollout approach
- `docs/pilot-plan.md` - detailed pilot structure
- `docs/requirements.md` - functional and non-functional requirements
- `docs/use-cases.md` - initial use cases and pilot selection guidance
- `docs/metrics.md` - how success will be measured
- `docs/risk-register.md` - identified risks and mitigations
- `docs/roles-and-responsibilities.md` - ownership and accountability
